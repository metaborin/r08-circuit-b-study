# 電気回路B・2学期期末 学習室

高校1年生向けの復習サイトです。コンデンサ・静電気と、電流がつくる磁界を学習します。電磁力は扱いません。

- 8単元の解説と段階式の例題
- 確認問題24問
- 授業スライドPDF 15本（追加12本はPowerPoint原本もダウンロード可）
- 授業・基礎復習動画 11本
- 公式ノートと計算シミュレーション

学習記録は使用中の端末・ブラウザ内に保存されます。氏名やメールアドレスの入力、先生への送信、端末間同期はありません。

## テスト範囲

試験時間は50分、電卓使用可（持参）。教科書の印刷ページ p.102–109、p.118–131 と、章末の指定問題が対象です。サイト内の「テスト範囲」で例題・問・節末問題・章末問題の番号を確認できます。任意のチャレンジは通常の範囲と区別しています。範囲表PDF自体は掲載していません。

## 開き方

公開サイトのURLをブラウザで開いてください。ダウンロードした場合は、フォルダ構成を保ったまま `index.html` をChromeまたはEdgeで開けます。

## GitHub Pages

公開元は `main` ブランチのルート `/` です。ビルド処理は不要です。教材は `assets/` に収録しています。

## 教材の収録方針

教科書をスキャンしたPDF原本は収録していません。授業スライドに組み込まれた図は維持しています。同じ内容の旧版は改訂版へまとめ、解説の構成が異なる動画・計算問題版は別教材として掲載しました。p.109問2や公式の導出など、授業教材に含まれる補足は各教材の注記で試験範囲と区別しています。
